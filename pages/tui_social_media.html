From TUI Rows to Print-Ready Assets

It turns raw Markdown and TOML stylesheets into print-ready PDFs and PNGs.

I dont use manual, drag-and-drop design canvases. They break down completely when you need programmatic layout stability and high-volume throughput. Instead, I built a custom Python TUI framework that treats data rows as decoupled multi-format assets.
